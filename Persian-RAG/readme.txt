## اجرای پروژه و اتصال به Open WebUI

برای استفاده از رابط گرافیکی Open WebUI و اجرای سیستم RAG، باید دو سرویس به‌صورت هم‌زمان اجرا شوند:

1. **RAG API:** مسئول اجرای پردازش‌های RAG، بازیابی اطلاعات از Qdrant و تولید پاسخ با Gemini.
2. **Open WebUI:** رابط کاربری گرافیکی برای تعامل با سیستم RAG از طریق مرورگر.

### 1. اجرای RAG API

ابتدا یک پنجره PowerShell باز کنید و دستورات زیر را اجرا کنید:

```powershell
cd E:\work\LLM\RAG\example

.\.venv\Scripts\Activate.ps1

uvicorn openwebui_api:app --host 127.0.0.1 --port 8501
```

پس از مشاهده پیام زیر، API آماده استفاده است:

```text
INFO: Uvicorn running on http://127.0.0.1:8501
```

برای اطمینان از عملکرد API، آدرس‌های زیر قابل بررسی هستند:

- مستندات API: http://127.0.0.1:8501/docs
- فهرست مدل‌ها: http://127.0.0.1:8501/v1/models

**نکته:** پنجره PowerShell را باز نگه دارید؛ بستن آن باعث متوقف شدن RAG API می‌شود.

### 2. اجرای Open WebUI

یک پنجره جدید PowerShell باز کنید (پنجره قبلی باید همچنان فعال باشد) و دستورات زیر را اجرا کنید:

```powershell
cd E:\software\OpenWebUI

.\.venv\Scripts\Activate.ps1

$env:DATA_DIR="E:\software\OpenWebUI\data"

open-webui serve --host 127.0.0.1 --port 3000
```

پس از اجرای موفق، رابط کاربری از طریق آدرس زیر در مرورگر قابل دسترسی است:

http://127.0.0.1:3000

### 3. تنظیمات اتصال Open WebUI به RAG API

این تنظیمات فقط در اولین راه‌اندازی لازم هستند و برای اجراهای بعدی نیازی به تکرار آن‌ها نیست.

از مسیر زیر وارد تنظیمات شوید:

`Admin Panel → Settings → Connections → OpenAI API Connections`

مقادیر اتصال:

| پارامتر | مقدار |
|---|---|
| Base URL | `http://127.0.0.1:8501/v1` |
| API Key | `local-rag-key` |
| Model ID | `persian-wikipedia-rag` |

پس از ذخیره تنظیمات، مدل `persian-wikipedia-rag` در فهرست مدل‌های قابل انتخاب در صفحه چت قرار می‌گیرد.

### 5. توقف سرویس‌ها

برای متوقف کردن هر سرویس، وارد پنجره PowerShell مربوط به آن شوید و کلیدهای `Ctrl + C` را فشار دهید.

### نکات مهم

- برای اجرای سیستم، هر دو سرویس باید هم‌زمان فعال باشند.
- ابتدا RAG API و سپس Open WebUI را اجرا کنید.
- آدرس‌ها و تنظیمات اتصال فقط در صورت تغییر پورت‌ها یا تنظیمات شبکه نیاز به اصلاح دارند.
- پورت‌های `3000` و `8501` در تنظیمات فعلی استفاده می‌شوند؛ در صورت بروز خطای اشغال بودن پورت یا محدودیت دسترسی ویندوز، باید پورت آزاد دیگری انتخاب و تنظیمات اتصال نیز متناسب با آن اصلاح شود.
- API Key فعلی صرفاً یک مقدار آزمایشی است و در کد فعلی اعتبارسنجی نمی‌شود. سرویس‌ها را فقط روی آدرس محلی `127.0.0.1` اجرا کنید.
